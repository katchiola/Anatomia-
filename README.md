# Anatomia Mágica 1.0
Protótipo web educativo com câmera, rastreamento de pose MediaPipe e órgãos 3D simplificados em Three.js.

## Executar
Hospede `index.html` em um serviço HTTPS estático (GitHub Pages, Netlify, Vercel) ou teste localmente em `localhost`.
Abra no Safari do iPhone ou Chrome do Android e permita acesso à câmera.
É necessária conexão com a internet para carregar bibliotecas e modelo de pose.

## Limitações
Posições anatômicas aproximadas; funciona melhor com uma pessoa de frente e ombros/quadris visíveis. Os modelos são formas 3D estilizadas, não malhas anatômicas clínicas. Não é ferramenta médica.
